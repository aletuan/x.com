Tóm tắt

Video so sánh Agent Skills và MCP (Model Context Protocol) trong kỷ nguyên Claude Code. Người trình bày giải thích MCP là gì: một agent nhận prompt từ user, gọi LLM để xử lý, nhưng LLM chỉ biết internet — không biết support tickets, wiki, Google Docs của công ty. MCP server đứng giữa, cung cấp tools và resources qua interface chuẩn hóa. Trong 9–12 tháng qua: hầu như không ai dùng resource API, community chuyển sang tools API (resource query = tool call). Cập nhật MCP: streamable HTTP (dễ deploy hơn SSE), OAuth 2.1 (user popup auth thay vì secret trong env). Skills là markdown file chứa hướng dẫn cho model, kèm resources (dữ liệu tĩnh) và scripts (bash, Python). Skills vs MCP: Skills thiên về static/local (file system), MCP thiên về real-time/cloud (tickets, Kafka). Với local coding agent, script gọi CLI có thể thay MCP; nhưng với agentic microservice chạy headless, MCP vẫn cần thiết. Kết luận: cần biết và dùng cả MCP lẫn Skills — đây là landscape phát triển nhanh nhất trong 30 năm software engineering.
