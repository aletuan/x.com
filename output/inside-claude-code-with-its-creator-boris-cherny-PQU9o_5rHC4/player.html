Tóm tắt

Boris Cherny, creator and engineer of Claude Code at Anthropic, joins The Light Cone podcast. He explains the philosophy: build for the model six months from now, not today. Claude Code has been rewritten entirely multiple times — no part existed 6 months ago. The approach: try things, give to users, learn, iterate. Plan mode might not be needed in a month as models improve. Discussion covers file organization, simplicity (Claude Code vs two Code), and the rapid evolution of LLM tooling.
