Tóm tắt

Barry Zhang và Mahesh Murag (Anthropic) trình bày về Agent Skills. Agents có intelligence nhưng thiếu domain expertise — giống Mahesh (genius) vs Barry (tax pro): bạn chọn Barry làm thuế. Code là universal interface; Claude Code thực ra là general-purpose agent. Scaffolding mỏng: bash + file system. Vấn đề: domain expertise. Skills = organized folders chứa procedural knowledge cho agents — đơn giản, version được trong Git, Google Drive. Skills có scripts as tools — self-documenting, modifiable, không chiếm context window. Progressive disclosure: chỉ metadata hiển thị lúc đầu, đọc skill.md khi cần. Ecosystem: foundational (document skills, Cadence scientific), third-party (Browserbase Stagehand, Notion), enterprise (Fortune 100, dev productivity teams). Skills + MCP: MCP = connectivity, skills = expertise. Non-technical (finance, legal) cũng build skills. Roadmap: testing/eval, versioning, skill dependencies. Vision: evolving knowledge base, Claude day 30 > day 1. Analogy: models = processors, agent runtime = OS, skills = applications. Stop rebuilding agents, start building skills.
