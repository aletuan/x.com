Tóm tắt

Video argues prompt engineering is dead — context is king. LLM has ~1M token window, not enough for complex agentic tasks. Six building blocks of context: user message, system prompt, tools, resources, assistant messages, tool calls/responses. Resources: private data (docs, wiki) — LLM only knows what it reads. 60–70% context fill often best. Four tools: (1) system prompt — not too vague, not too prescriptive; (2) tool descriptions — specific, with schema; (3) data retrieval — RAG vs MCP, model can prompt for resources; (4) long-horizon: compaction (summarize), memory (key-value store), agent composition (split into sub-agents). Confluent Intelligence for streaming agents.
